# Tic-Tac-Toe Backend

Backend веб-приложения «Крестики-нолики», написанный на Python и Flask.

Проект является продолжением предыдущего проекта с игровой логикой. В этой версии добавлены PostgreSQL, пользователи, авторизация и возможность игры между двумя пользователями.

## Features

- регистрация пользователей;
- авторизация через Basic Authentication;
- хранение пользователей и игр в PostgreSQL;
- работа с базой данных через SQLAlchemy;
- создание игры;
- поиск доступных игр;
- подключение второго игрока;
- игра пользователя против пользователя;
- игра против компьютера;
- определение текущего состояния игры;
- состояния ожидания, хода игрока, ничьей и победы;
- UUID для идентификации пользователей и игр;
- REST API;
- обработка ошибок авторизации;
- разделение приложения на слои.

## Project structure

Приложение разделено на несколько слоёв:

- `domain` — бизнес-логика и модели;
- `datasource` — работа с базой данных и репозиториями;
- `web` — маршруты, DTO и обработка HTTP-запросов;
- `di` — dependency injection.

## Technologies

Python, Flask, PostgreSQL, SQLAlchemy, REST API, Basic Authentication, UUID, HTML, CSS, JavaScript
